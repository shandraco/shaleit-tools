    Questions people ask

    Do QR codes expire?

    No. The codes made here are static, which means the web address, Wi-Fi details or text is stored in the pattern itself with no server in between. They never expire and need no subscription. A code only stops being useful if the page it points to moves or is deleted.

    Is it safe to make a QR code here?

    Yes. The code is drawn inside your browser, so the address, Wi-Fi password or text you type is never sent anywhere or stored. Before you print it, scan the finished code with your phone to be sure it opens the right place and nothing else.

    Can I make a QR code for my Wi-Fi?

    Yes. Choose Wi-Fi network, type the network name and password, and pick the security type, which is usually WPA. Most modern phones can scan the code and join the network without anyone typing the password. Print it and stick it somewhere guests can see it.

    Should I download a PNG or an SVG?

    Download a PNG for most uses, such as a document, slide or website. Choose SVG if you are sending the code to a print shop or need it very large, because an SVG stays sharp at any size while a PNG is made of a fixed number of pixels.
