    Questions people ask

    What sizes does a favicon need?

    Most sites need a 32 by 32 pixel icon for browser tabs, a 16 by 16 pixel one for small spaces, a 180 by 180 pixel Apple touch icon for iPhones, and 192 and 512 pixel icons for Android. The pack made here includes all of these, plus a 48 pixel favicon.ico.

    What file format should a favicon be?

    Use PNG for the sized icons and an ICO file for the classic favicon.ico that older browsers look for. The pack made here includes both, along with a small web manifest file for Android. An SVG icon also works in current browsers if you have one.

    Where do I put the favicon files?

    Upload the files to the top folder of your website, so they sit next to your home page. Then paste the short block of code this tool shows into the head of your pages. Browsers cache favicons for a while, so a new icon can take a day to appear.

    Does my image need to be square?

    A favicon is always square, so the best starting image is square and simple. If yours is not, choose Fit whole image to keep everything, or Fill the square to trim the edges. Fine detail vanishes at 16 pixels, so a bold shape or one or two letters work best.
